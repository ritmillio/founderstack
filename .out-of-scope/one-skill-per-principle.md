# One skill per principle

**Decision:** principles live in one file (`founder-mode/principles.md`), not
as separate skills.

**Why:** each extra skill costs description space in every session and adds a
lookup. Sixteen short rules read in one go cost less than sixteen skill loads,
and the agent sees how they relate. pstack chose the other way because its
principles are hidden behind its router; both work, and this one is cheaper.
