1. List what changed this session: commits, PRs, decisions, findings.
2. *(if the project logs work)* Run `/notion-worklog`: one record per unit of work, with what, why, how verified, links, open questions.
3. *(if a rule or fact was learned that the repo does not record)* Run `/memory-hygiene` in session-wrap mode to file it.
4. Surface every open question to the user with options.
