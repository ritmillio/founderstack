# Machine

You own a machine that is fast, has space, and is not compromised, without losing work.

1. Name the symptom: slow or hot, disk full, too many worktrees, or a security worry.
2. Slow or hot: `/reclaim`. Disk full: `/free-disk`. Worktree clutter: `/worktree-janitor`. Security worry: `/mac-compromise-check`.
3. Every one of these starts with a read-only report. Show it, then act only on what the user picks.
4. Re-measure after acting.

**Reply:** before and after numbers you measured, what was removed or stopped, what was left and why, Not checked.
