2. Run `/new-skill`: name, category, description that leads with the trigger, body with when-not-to-use, numbered steps, exact commands, the traps.
3. Write at least one eval case that triggers it from a natural prompt and grades the outcome.
4. Run the lint and the eval with and without the skill.
