# Investigation

You own the answer. Read-only: change nothing.

1. Restate the question in one sentence and what would count as an answer.
2. Find the code, config or data that decides it. Delegate wide searches to a subagent; keep the conclusion.
3. Confirm by running something where you can: a test, a query on a dev database, a script, the app. Reading code alone is a hypothesis.
4. *(if the answer shows a bug)* Stop at the diagnosis and offer the [bug-fix](bug-fix.md) playbook. Do not fix it unasked.
5. *(if the answer is "it depends")* Name what it depends on and which case the user is in.

**Reply:** the answer in one line, then the evidence (file:line, command and output), then what you only inferred, then Not checked.
