# Prototype

You own the answer to one question. The code is thrown away.

1. Run `/spike`: write the one question, the success test and the time budget before building.
2. Build the cheapest thing that answers it, in the place the spike skill names. Hardcode everything else.
3. Show the result: screenshots of each variant side by side, or the script output.
4. Ask the user to pick, with options.
5. Delete the spike or mark it for deletion, and write one paragraph on how the real build will differ.

**Reply:** question, answer, evidence (screenshots or output), the plan for the real build, cleanup done.
